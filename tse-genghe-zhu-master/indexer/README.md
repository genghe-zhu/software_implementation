## indexer
`indexer` reads documents from pageDirectory which is output from crawler, and then builds an inverted index mapping word to documents in a file.

`indexTest` loads an index file generated from indexer and stores it in a file

## Assumptions
The number of document IDs is an integer. 

## Usage
To run indexer, give three arguments from command line 
1. program itself
2. pathname of directory from `crawler` output
3. pathname of file where index will be stored

ex: ./indexer pageDirectory indexFilename

To run indextest, give three arguments from command line
1. program itself
2. pathname of file generated by `indexer`
3. filename where index is written to

## Compilation
Run `make all`
# manual test
Run `make test`
# use script to test
Run `source indextest.sh`
